Practice 11 – Pygame Projects

This project extends the previous Practice 8 work and includes three mini-games/applications built using Python + Pygame.

📌 Contents
Racer
Snake
Paint
🚗 1. Racer
Description

A simple racing game where the player controls a car and avoids enemies while collecting coins.

Extra Features
🪙 Randomly generated coins with different weights on the road
⚡ Enemy speed increases when the player collects N coins
💬 Fully commented code for better understanding
Gameplay
Collect coins to increase score
Avoid enemy cars
Game becomes harder over time
🐍 2. Snake
Description

Classic Snake game where the player controls a snake to eat food and grow longer.

Extra Features
🍎 Randomly generated food with different weights (scores)
⏳ Food disappears after a certain time (timer system)
💬 Fully commented code
Gameplay
Eat food to grow and increase score
Avoid hitting walls or yourself
Some food gives more points but disappears faster
🎨 3. Paint
Description

A simple paint application built with Pygame for drawing different shapes.

Extra Features
⬛ Draw square
🔺 Draw right triangle
🔻 Draw equilateral triangle
♦️ Draw rhombus
💬 Fully commented code
Tools
Free drawing
Shape tools
Color selection (if included in your base project)
